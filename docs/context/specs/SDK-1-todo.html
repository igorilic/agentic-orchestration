SDK-1 — Todo plan (atomic TDD steps)

July 13, 2026

Spec: docs/context/specs/SDK-1-spec.html ADR: docs/decisions/ADR-002-sentinel-stream-and-sidekick-delegation.html Driver: tdd-developer. Total: 6 (Track A) + 10 (Track B, incl. integration) = 16 steps.

Two tracks. The sentinel grammar is frozen in the spec (OQ-1) and is the shared contract: Track A teaches agents to emit it; Track B renders + persists it.

A → B dependency (explicit): Track B steps B1–B8 are built against committed fixtures that match the frozen grammar and can proceed in parallel with Track A. The integration step B9 and all real-world value require Track A merged (agents actually emitting sentinels/delegations). A-1 is a hard GO/NO-GO gate for the delegation half — do not build A-2..A-5 until it passes. A-6 is independent of the A-1 gate — it adds narration + verdict, no Task/sidekick dispatch — and can land any time after A-5. No Track B step hard-depends on A-6: the renderer persists whatever it is fed, and B-1..B-9 run against committed fixtures. B-9's e2e fixture may optionally be widened to the full five-agent stream + verdicts to exercise A-6 end-to-end, but the true dependency is the real live view / full-pipeline fidelity — without A-6 the live view goes dark during requirements-engineer and reviewer, and verdict has no producer.

Each step: one RED test runnable today (bats tests/<file>.bats), one TDD cycle (~30 min), one commit (or test+impl as two commits per local TDD style). The renderer mechanics are already de-risked in spikes/sdk-1-renderer/ — Track B ports and reuses them, it does not redesign them.
